About this tool
This is a field notebook, not the register itself. Each capture is saved as one self-contained file into your device Downloads, which your sync app copies to the shared drive inbox/ folder. On the desktop, the register imports each file as a notebook entry that can be escalated to a full complaint. No file number is allocated in the field — that happens at the desk. Works fully offline.
